
# Simple BMI Calculator

A beginner-friendly BMI calculator built with Python.

## Features
- Takes weight in kilograms and height in meters
- Calculates BMI
- Displays BMI rounded to two decimal places
- Classifies BMI into categories
- Checks for non-positive weight and height

## Formula
BMI = weight (kg) / height (m)^2

## How to Run
1. Install Python 3.
2. Download `bmi_calculator.py`.
3. Open a terminal in the file's folder.
4. Run:

   python bmi_calculator.py

5. Enter your weight and height when prompted.

## Example
Weight: 70 kg  
Height: 1.75 m  
BMI: 22.86  
Category: Normal
